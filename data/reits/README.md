# REIT Benchmark Data

The primary REIT benchmark is the Residential sector of the FTSE Nareit U.S. Real Estate Index Series.

- Geographic scope: United States
- Property sector: Residential
- Currency: U.S. Dollars
- Return type: Annual Total Return
- Analysis period: 2022–2025
- Role: Primary comparison benchmark

## 3. Interpretation

The U.S. Residential REIT index is used as the primary benchmark because the RealT sample consists of U.S. residential rental properties.

The STO capital-return measure excludes rental distributions, whereas the official REIT total-return measure includes both price changes and distributions. Their comparison is therefore interpreted as a descriptive comparison of price-adjustment patterns, not as a direct comparison of performance superiority.

ETF adjusted-price data are not official index observations and are not used in the main analysis.
