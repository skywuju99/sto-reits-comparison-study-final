# 부동산 토큰·리츠 비교 연구 재현자료

최신 논문의 RealT 자산정보와 YAM·Swapcat 거래 분석을 재현하는 저장소입니다. **현재 분석 버전은 `empirical-20261023-v1`**이며, 2026년 10월 24일 공개용 파일 배치와 최신 논문 표 번호를 정리했습니다. 국내 IPI 채점은 이 거래자료 계산과 별개입니다.

## 실행

Python 3.11 이상에서 저장소를 내려받은 뒤 다음을 실행합니다.

```sh
python -m pip install -r requirements.txt
python run_all.py
```

보존 입력자료 중 대용량 원시 거래 CSV 2개는 기존 공개 Release v2.0.0에서 최초 실행 시 자동으로 내려받습니다. 나머지 입력은 저장소에 포함합니다. API키는 필요 없으며, 내려받은 압축파일과 각 원자료의 SHA-256을 확인합니다. 기존 릴리스의 **원자료는 동일함을 대조했지만 과거 처리 결과는 사용하지 않습니다**. 이후 입력이 준비된 상태에서는 인터넷 없이 실행할 수 있습니다. 원자료에서부터 정규화·이월·수량 대조·계산·독립 검산을 수행합니다. 과거 체인 로그를 RPC에서 새로 수집하는 작업은 포함하지 않습니다.

산출물은 `replication/empirical-20261023-v1/results/`에 생성됩니다. 파일명에 남은 예전 표 번호 대신 아래 **현재 논문 대응표**를 사용하십시오.

반올림 전에 합산합니다. 가중치는 각 연도 결합표본의 **기초 플랫폼 총투자금 비중**입니다. 임대정보는 연말 기록상 연환산 값이며 실제 연간 지급 분배금이 아닙니다. 따라서 이 값은 실현수익률이 아닙니다. 리츠 비교값은 논문에서 확인한 Nareit Residential USD 연간 총수익률 4개 관측값이며 이 실행에서 원문을 다시 수집하지 않습니다. 원출처: [Nareit Annual Index Values & Returns](https://www.reit.com/data-research/reit-market-data/report/annual-index-values-returns).

2025년 **가격 공통표본 382개·거래대금 가중 −15.15%**와 **임대 결합표본 381개·수익률 근사치 −6.80%**는 표본과 지표가 다릅니다. Marloes는 가격 분석에는 유지하고 임대 결합에서만 제외했습니다.

자료별 기준과 해시는 [`docs/table_file_map.csv`](replication/empirical-20261023-v1/docs/table_file_map.csv), 입력 해시는 [`inputs_manifest.json`](replication/empirical-20261023-v1/inputs_manifest.json)에 기록됩니다. 원고는 2026년 10월 23일 수정본의 표 번호에 대응합니다.

## 분석 방법과 해석 범위

- 관찰가격: 구간 내 체결금액 합계 ÷ 체결수량 합계(VWAP). 기본 관찰기간은 90일입니다.
- 개별 가격변화율: 기말 VWAP ÷ 기초 VWAP − 1. 표 4-6은 기말 90일 거래대금 비중으로 가중합니다.
- 임대정보 환산: 연말 기록상 `netRentYear` ÷ 적용 토큰 수 ÷ 기초 VWAP. 가격변화율과 더한 뒤 기초 플랫폼 총투자금 비중으로 가중합니다.
- 연말 상태: 부분 갱신 이력을 누적하고 갱신 없는 필드는 직전 기록값을 이월합니다. 갱신이 없다는 사실은 임대료 수취 지속의 증거가 아닙니다.
- 2023년 확인된 12개 S형·D형 사례는 동일 자산의 합산 수량을 적용합니다. 자산의 임대정보를 이중 계산하거나 D형 가격을 S형 거래가격에 합치지 않습니다.
- Marloes는 임대정보와 적용 수량 범위가 미확정이므로 임대 결합에서 제외합니다. 수량 대조는 모든 클래스의 법적 권리·실제 지급액을 입증하지 않습니다.
- 30·90·180일 비교는 세 구간의 공통표본과 기말 90일 거래대금 가중치를 고정합니다. 2022·2023년은 부호가 달라지고, 2025·2026년은 하락 방향이 유지됩니다. 가격변화율의 검토를 임대 결합 근사치 전체의 강건성 검증으로 확대하지 않습니다.
- 2026년 공통 종료시각은 **2026-07-06 20:28:20 UTC**입니다. 이후 YAM 1,502건을 제외하며, 2026년은 부분연도 분석입니다.
- 미국 소재 분류집합 404개는 기존 포함 표시와 미국 주 코드·제외 키워드로 선정한 주소 집합입니다. `is_us_residential`은 기존 필드명이며 개별 부동산 용도를 전수 확인했다는 의미가 아닙니다.
- 플랫폼 825개, 분류주소 404개, 연중 거래 389개, 양 연말 가격 382개, 임대 결합 381개는 서로 다른 집합입니다. 825→404를 단순 순차 탈락으로 해석하지 않습니다.
- 거래빈도·최근 거래 후 경과일·미관찰 비중은 거래활동 지표입니다. 스프레드·시장 깊이·매도 소요기간은 측정하지 않았습니다.
- 월별 전체 VWAP는 월별 구성 변화가 있는 관찰가격이며 고정 포트폴리오 가격지수가 아닙니다. 표시가격 비교는 2026-04-06 보존값을 사용한 서로 다른 시점의 보조 비교입니다.

## 검증과 변경 이력

`run_all.py`는 최종 27개 CSV의 해시를 보존된 논문 결과와 대조하고, 모든 입력 해시와 자산별 합산, 거래활동 및 15개 고정표본 관찰기간 결과를 검증합니다. 독립 검산은 `results/independent_verification.json`, 실행 정보는 `run_manifest.json`에 기록합니다. 최초 검증 환경은 Python 3.12.14, pandas 3.0.1, NumPy 2.3.5입니다. CSV의 바이트 단위 대조는 이 고정 패키지 버전을 기준으로 합니다. 이는 보존 원자료에 대한 산술·실행 재현성 검증이며 원자료의 완전성이나 실제 지급 현금흐름을 별도로 입증하지 않습니다.

이전 공개 자료와 Release v2.0.0은 [archive/v2.0.0](archive/v2.0.0/) 및 기존 Git 이력에 보존합니다. 243개·−5.32%, 이후 382개·−6.69%, 30·60·90일 비교, 글로벌 리츠 보조지표 등은 과거 분석에 해당하며 현재 논문 결과와 혼용하지 않습니다. 최신 분석에는 글로벌 리츠 비교를 사용하지 않습니다.

주요 변경: 연말 상태 이월, S형·D형 수량 대조, Marloes 제외, 연도별 재계산, 집합 관계표, 거래빈도·경과일·미관찰 비중, 30·90·180일 동일표본 비교, 최신 표 번호 대응 및 원자료 해시 검증·다운로드 경로.
