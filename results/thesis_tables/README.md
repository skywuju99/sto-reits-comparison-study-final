# Thesis Table Replication Outputs

These CSV files reproduce the values reported in the final thesis tables.

Important limitations:

- Table 5-3 and Table 5-4 use platform annual data and exploratory proxies.
- Table 5-9 reports observed capital returns based on year-end 90-day VWAPs.
- Table 5-10 combines platform annual-net-rent proxies with observed capital returns.
- Table 5-11 is a non-contemporaneous supplementary comparison using the RealT tokenPrice snapshot collected on 2026-05-24 as a common reference.
- Year-specific samples in Table 5-11 differ. Changes across years are not a continuous same-asset pricing-gap series.
- Table 5-12 contains selected monthly points, not the complete monthly panel.
- Table 5-7 is not included because the exact variable name and unit in Smith and Baur (2025) must be verified before publication.
