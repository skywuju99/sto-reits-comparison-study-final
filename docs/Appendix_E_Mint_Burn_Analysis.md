# Appendix E. RealToken Mint and Burn Analysis

## E.1 Identification Rule

Mint and burn events are identified from RealToken Transfer events:

- zero address to a non-zero address: mint;
- non-zero address to the zero address: burn.

Ordinary wallet-to-wallet transfers are not classified as mint or burn events.

## E.2 Coverage

The collection universe combines token addresses observed in:

- YAM metadata;
- YAM trading records; and
- Swapcat trading records.

The final address union contains 791 token addresses.

Mint or burn events are available for 785 addresses. The remaining six addresses are payment, stablecoin, governance, or ecosystem tokens rather than property RealTokens and are excluded from the property-token analysis.

This mint-and-burn collection universe is broader than the final U.S. residential secondary-market classification used in the main return analysis. The final 404-address U.S. residential classification is defined separately in `data/metadata/asset_master_clean.csv` and is not used to redefine the 791-address mint-and-burn collection universe.

Accordingly, the figures of 791 addresses and 404 addresses refer to different analytical universes and should not be compared as if one were a subset count generated by the same filtering stage.

## E.3 Event Records

The complete event file contains:

- 20,687 mint and burn events;
- 6,731 mint events; and
- 13,956 burn events.

These event counts should not be interpreted directly as the number of separate property offerings or exits. A single asset may generate multiple investor-level burn transactions.

## E.4 Event-Pattern Classification and Analytical Use

For descriptive purposes, the observed on-chain event patterns are classified as:

- initial mint;
- additional mint;
- partial burn; and
- full burn.

These classifications refer only to the timing and pattern of observed on-chain Transfer events.

Mint and burn records are used to document the occurrence and timing of token creation or destruction events. They are not used to infer the underlying economic purpose of the event.

In particular, a burn event alone does not establish whether the cause was a property sale, investor redemption, liquidation, token migration, contract restructuring, or another technical or economic event.

Accordingly, the mint and burn analysis is descriptive and does not assign an economic reason to individual burn events without an independent authoritative source.

The mint-and-burn dataset is therefore used as supplementary evidence on token-supply events and does not enter the primary 90-day VWAP capital-return calculation.
