# Appendix F. REIT Benchmark

## F.1 Benchmark definition

The main REIT benchmark is:

- Index series: FTSE EPRA Nareit Global Real Estate Index Series
- Geographic scope: Global
- Currency: USD
- Return type: Total Return
- Analysis period: 2022–2025

## F.2 Annual returns

| Year | Annual total return |
|---:|---:|
| 2022 | -23.58% |
| 2023 | 9.78% |
| 2024 | 1.57% |
| 2025 | 11.04% |

## F.3 Source

The values are taken from the Nareit Global Returns document, specifically the Global, USD, Annual, Total Return series.

Official source link:

`https://www.reit.com/sites/default/files/returns/GlobalReturns.pdf`

## F.4 ETF proxy data

ETF adjusted-price data for VNQ, VNQI, IYR, REZ, and RWR are not official index observations.

They may be retained for supplementary or robustness analysis but must not replace the official REIT benchmark in the main analysis.
